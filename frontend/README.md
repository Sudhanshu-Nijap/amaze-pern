# Amaze Frontend

This is the React frontend for the Amaze product tracker. It is built using Vite, Tailwind CSS, and React Router.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure environment variables in `.env`.
3. Run the development server:
   ```bash
   npm run dev
   ```

For full project documentation, please refer to the [Root README](../README.md).
